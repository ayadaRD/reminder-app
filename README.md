# یادآور | اجرای نسخهٔ توسعه روی Redmi Note 13 Pro

## ۱. آماده‌سازی ویندوز

1. [Git برای ویندوز](https://git-scm.com/download/win) و [VS Code](https://code.visualstudio.com/) را نصب کن.
2. در VS Code کلیدهای Ctrl+Shift+X را بزن و افزونهٔ **Flutter** را نصب کن. برای نصب SDK، [راهنمای رسمی نصب Flutter در VS Code](https://docs.flutter.dev/install/with-vs-code) را دنبال کن. اگر گزینهٔ **Add SDK to PATH** دیدی، آن را انتخاب کن و VS Code را دوباره باز کن.
3. [Android Studio](https://developer.android.com/studio) را برای Android SDK و ابزارهای ساخت نصب کن. کدنویسی و اجرا را در VS Code انجام می‌دهی. از SDK Manager موارد Android SDK Platform، Build-Tools، Command-line Tools و Platform-Tools را نصب کن. در صورت درخواست flutter doctor، نسخهٔ SDK یا NDK موردنیاز را نیز اضافه کن.
4. در VS Code از منوی **Terminal → New Terminal** این دستورها را اجرا کن. برای پذیرش مجوزهای Android، هر جا پرسید y بزن.

```powershell
flutter --version
flutter doctor --android-licenses
flutter doctor -v
```

## ۲. اتصال گوشی با کابل دیتا

1. در **Settings → About phone** چند بار روی **OS version** یا **MIUI version** بزن تا Developer options فعال شود.
2. در **Settings → Additional settings → Developer options** گزینهٔ **USB debugging** را روشن کن.
3. گوشی را با کابل دیتا وصل کن، قفلش را باز کن و پیام **Allow USB debugging** را تأیید کن. اگر ویندوز گوشی را تشخیص نداد، کابل/درگاه دیگر و درایور USB سازنده را بررسی کن.
4. در ترمینال بزن:

```powershell
flutter devices
```

اگر گوشی در فهرست نیامد، اول همین مرحله را حل کن. اگر گوشی دیده شد ولی نصب با خطای USB مواجه شد، تنظیم **Install via USB** را در Developer options بررسی کن.

## ۳. ساخت پوشهٔ پروژه و اجرا

1. فایل ZIP را Extract کن و پوشهٔ `reminder` را با **File → Open Folder** در VS Code باز کن.
2. در Terminal این دستور را فقط برای آماده‌سازی اولیه اجرا کن:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\bootstrap.ps1
```

3. بعد از پیام Ready، پوشهٔ `app` را با **File → Open Folder** باز کن. از پایین VS Code گوشی را انتخاب کن و **F5** بزن. از ترمینال همان پوشه هم می‌توانی `flutter run` بزنی. اولین Build ممکن است چند دقیقه طول بکشد.
4. برای ویرایش ظاهر و متن، `app/lib/main.dart` را باز کن. منطق تکرار در `app/lib/schedule.dart` است. تغییر Dart معمولاً با Hot Reload اعمال می‌شود. برای تغییر فایل‌های Java یک بار اجرا را متوقف و دوباره شروع کن.

## ۴. تست روی گوشی

- در تنظیمات خود اپ، وضعیت اعلان‌ها، آلارم دقیق و دسترسی صفحهٔ قفل را بررسی کن.
- یک یادآور **دلخواه** با روش آلارم و زمانی دو دقیقه جلوتر بساز. برنامه را از Recent Apps ببند و صفحه را قفل کن. پخش مداوم و دکمهٔ قطع را بررسی کن.
- همین تست را با یکی از صداهای آماده و یک فایل صوتی گوشی تکرار کن.
- برای دارو، روی یک نام آزمایشی دو بار تست کن: یک‌بار «مصرف شد» و یک‌بار «۱۰ دقیقه بعد». در فهرست داروها زمان آخرین ثبت مصرف را بررسی کن.
- برنامه را دوباره باز کن و بررسی کن یادآورها باقی مانده‌اند. برای تست بازیابی بعد از ری‌استارت، ابتدا یک نوبت آزمایشی در آینده ثبت کن.
- تاریخ تولد، هفته‌گرد، ماهگرد، آبیاری و موعد خودرو را در تقویم بررسی کن. آب و دارو در تقویم نمایش داده نمی‌شوند. برای دلخواه، کلید نمایش در تقویم را امتحان کن.
- اگر آلارم روی صفحهٔ قفل نمی‌آید، ابتدا مجوزهای خود برنامه را بررسی کن. نام تنظیمات پس‌زمینه و باتری در نسخه‌های HyperOS/MIUI فرق می‌کند. **Force stop** در تنظیمات اندروید با بستن برنامه از Recent Apps فرق دارد و برای تست عادی استفاده نمی‌شود.

داده‌ها در حافظهٔ خصوصی اپ روی گوشی هستند. نسخهٔ فعلی نوبت‌های پرتکرار را برای ۴۰۵ روز آینده آماده می‌کند و هنگام باز کردن برنامه، بعد از گذشت یک هفته از آخرین زمان‌بندی، این بازه را تمدید می‌کند. نسخهٔ فعلی روی دستگاه واقعی کامپایل و تست نشده است.
